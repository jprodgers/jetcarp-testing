# Step 3: the host's crash. 2026-11-12, Acer, jetcarp c5a58fc.

On the Acer's real GPUs nothing crashed: steps 1, 2, 4 and 5 all kept their host, and the
Application log had no jetcarp entry from 04:30 to 04:48.

It crashes on the software renderer, WARP ("Microsoft Basic Render Driver"), which is what
GitHub's Windows runners have. The host can't be told to use WARP, so the throwaway clone got a
debug switch (07-debug-switch.diff: JETCARP_DEBUG_FALLBACK sets force_fallback_adapter in
SharedGpu::headless). With it, jetcarp host start --headless printed "running ... GPU Microsoft
Basic Render Driver" and the host was gone within seconds. Event Viewer, Application log:
